🚀 1) Arquivo app.py (código simples + explicação detalhada)

Aqui está o código final.
A explicação vem logo abaixo, comando por comando.

from flask import Flask, render_template, request, redirect
import sqlite3

app = Flask(__name__)

# cria banco e dados iniciais
conn = sqlite3.connect("data.db")
conn.execute("CREATE TABLE IF NOT EXISTS itens (id INTEGER, label TEXT, valor TEXT)")
if conn.execute("SELECT COUNT(*) FROM itens").fetchone()[0] == 0:
    conn.execute("INSERT INTO itens VALUES (1,'Dia','Sexta')")
    conn.execute("INSERT INTO itens VALUES (2,'Mês','29')")
    conn.execute("INSERT INTO itens VALUES (3,'Bitcoin','57000')")
conn.commit()
conn.close()

@app.route("/")
def index():
    conn = sqlite3.connect("data.db")
    itens = conn.execute("SELECT * FROM itens").fetchall()
    conn.close()
    return render_template("index.html", itens=itens)

@app.route("/admin", methods=["GET","POST"])
def admin():
    conn = sqlite3.connect("data.db")
    if request.method == "POST":
        for id in [1,2,3]:
            v = request.form.get(f"i{id}")
            conn.execute("UPDATE itens SET valor=? WHERE id=?", (v,id))
        conn.commit()
        conn.close()
        return redirect("/")
    itens = conn.execute("SELECT * FROM itens").fetchall()
    conn.close()
    return render_template("admin.html", itens=itens)

app.run(debug=True)

🧠 2) Explicação dos comandos (cada um, de forma fácil)

Agora vem a parte importante: entender como criar seu próprio painel.


---

🔵 1) Imports

from flask import Flask, render_template, request, redirect
import sqlite3

❗ O que significa:

Flask → cria o site.

render_template → carrega páginas HTML.

request → pega dados enviados por formulário.

redirect → redireciona para outra página (ex: voltar para “/”).

sqlite3 → conecta em um banco de dados simples (arquivo data.db).



---

🔵 2) Criação do app

app = Flask(__name__)

Isso cria o aplicativo Flask.


---

🔵 3) Criando banco e dados iniciais

conn = sqlite3.connect("data.db")

Abre (ou cria) o banco.

conn.execute("CREATE TABLE IF NOT EXISTS itens (id INTEGER, label TEXT, valor TEXT)")

Cria a tabela só se não existir.
Essa tabela tem:

id → número (identificador)

label → nome (ex: "Dia")

valor → valor (ex: "Sexta")


if conn.execute("SELECT COUNT(*) FROM itens").fetchone()[0] == 0:

Se a tabela estiver vazia…

conn.execute("INSERT INTO itens VALUES (1,'Dia','Sexta')")
...

…então insere valores padrão.

conn.commit()
conn.close()

Salva e fecha o banco.


---

🔵 4) Página pública (home): “/”

@app.route("/")
def index():

Quando acessar http://localhost:5000/, essa função roda.

conn = sqlite3.connect("data.db")
itens = conn.execute("SELECT * FROM itens").fetchall()

Pega todos os itens da tabela.

return render_template("index.html", itens=itens)

Envia a lista itens para a página index.html.


---

🔵 5) Página do Painel: “/admin”

@app.route("/admin", methods=["GET","POST"])
def admin():

Aceita GET (abrir página) e POST (enviar formulário).


---

✔️ Se for POST (ou seja, cliente clicou “Salvar”)

if request.method == "POST":

v = request.form.get(f"i{id}")

Pega o valor digitado no formulário.

conn.execute("UPDATE itens SET valor=? WHERE id=?", (v,id))

Atualiza o banco.

return redirect("/")

Volta para a página principal.


---

✔️ Se for GET (só abrir o painel)

itens = conn.execute("SELECT * FROM itens").fetchall()

Pega os dados do banco.

return render_template("admin.html", itens=itens)

Carrega o painel com os itens.


---

🔵 6) Rodar o servidor

app.run(debug=True)

Inicia o servidor Flask.
debug=True faz ele reiniciar sozinho quando você salva arquivos.

📄 3) HTML da página pública

templates/index.html

<h1>Olá Mundo</h1>

<table border="1">
  {% for i in itens %}
  <tr><td>{{ i[1] }}</td><td>{{ i[2] }}</td></tr>
  {% endfor %}
</table>

<a href="/admin">Painel</a>

Explicando:

{% for %} = comando do Flask dentro do HTML.

{{ i[1] }} mostra o texto.

href="/admin" leva ao painel.



---

📄 4) HTML do painel

templates/admin.html

<h1>Painel</h1>

<form method="post">
  {% for i in itens %}
    <p>{{ i[1] }}: <input name="i{{ i[0] }}" value="{{ i[2] }}"></p>
  {% endfor %}
  <button>Salvar</button>
</form>

<a href="/">Voltar</a>

Explicando:

<form method="post"> → envia dados para atualizar o banco.

input name="i{{ i[0] }}" → o nome do campo vira i1, i2, i3.

<button> → envia o formulário.

Flask → painel + banco + rotas (mas programado por você).
